## Скан экстремального фандинга по всем перпам (малый капитал — ёмкостный край)

Единственный класс края, где малый капитал не недостаток: захеджированный керри (шорт
перпа + лонг спота) на эпизодах, когда ставка улетает выше 100% годовых — фонды
в мелкие перпы не заходят. `funding_scan.py` качает историю фандинга по ВСЕМ
USDT-перпам Binance (текущий список, survivorship есть), берёт только монеты со
спотом к USDT (иначе не захеджировать), правило объявлено заранее: вход после
`--confirm` выплат подряд ≥ `--enter` % годовых, выход после выплаты < `--exit`,
издержки `--cost` bp за эпизод, базис игнорируется (консервативно). Считает
верхнюю границу «взяли всё по $10k» и симуляцию $10k на `--slots` слота.

Первый раз ~5 минут, фоном (лог `funding_scan.log`):

```bash
cd ~/PycharmProjects/stooq_detect && nohup sh -c '.venv/bin/python funding_scan.py --fetch --scan --confirm 3' > funding_scan.log 2>&1 &
```

```bash
cd ~/PycharmProjects/stooq_detect && tail -60 funding_scan.log
```

Пересчёт без сети с другими порогами (чувствительность, не подбор):

```bash
cd ~/PycharmProjects/stooq_detect && .venv/bin/python funding_scan.py --scan --enter 50 --confirm 3
```

**Полный скан 19.09 (658 перпов, 364 со спотом, 2019-09 – 2026-09): ветка
ЗАКРЫТА.** Эпизодов 1125, в плюсе 58%, средний net +1.02% нотионала — но всё
это 2020–2021 (2021: сумма net +1001% нотионала, IOTA/TRB/ANKR по +14–15% за
три недели) и всплеск начала 2024 (+105%). 2023: −5%, 2025: −8%, 2026: −9%,
в плюсе 21% и 4% эпизодов. Симуляция $10k/3 слота: +$444 в год в среднем,
2025 −$258, 2026 −$283, последние 12 месяцев −$293. Причина видна в данных:
с 2023 интервал выплат 4 часа вместо 8, медианный эпизод 0.5–0.7 дня вместо
3 — всплеск ставки снимают боты за одну-две выплаты, издержки 50 bp съедают
остаток. Оптимистичная граница (вход на прогнозной ставке, выплата входа
засчитана) при порогах 100/200/300% годовых: 2025 от −4% до +5% нотионала
суммой по ВСЕМ эпизодам, 2026 от −7% до −1% — то есть даже взяв всё и
бесплатно, в 2025–2026 не заработать. Свежие листинги: средний фандинг −53%
годовых (шортят толпой; платят лонгам), выше 100% — 5% листингов. Делистнутые
перпы в выборке отсутствуют (survivorship) — реальность хуже цифр.
Ёмкостного края для малого капитала на фандинге в 2025–2026 нет.

### Грабли, на которые уже наступали

- `collector/check.sh` работает **только на сервере** (там ClickHouse в docker
  compose). Локальный запуск теперь сам об этом говорит и выходит.
- Kraken ws v2, канал `ticker`: по умолчанию `event_trigger: "trades"` —
  обновления приходят только на сделку. Для xStocks это 1 строка в 8 минут.
  Лечится `event_trigger: "bbo"` (уже сделано, env `KRAKEN_BBO_SYMBOLS`).
  Рабочий лидер на накопленных данных — `idx_gate_SPY` (97.9% минут).
- `lag_ms = 0` у kraken — не «мгновенно», а «нет биржевого времени»
  (`ts = recv_ts`). Реальная задержка измерена только у gate: 113–116 мс.
- Для нового инструмента-цели направление сделки берётся по знаку β к лидеру,
  а не по аналогии «тоже российский»: Si идёт ПРОТИВ S&P.
- Классический REST Kraken `AssetPairs` не перечисляет xStocks — пустой ответ
  там ничего не значит, источник правды — живой ws (`--probe`).
